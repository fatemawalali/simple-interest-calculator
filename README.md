# Simple Interest Calculator

## About the Project
This project is a simple interest calculator made using HTML, CSS, and JavaScript. It helps users calculate simple interest based on the amount of money, interest rate, and number of years.

## Features
- Enter the principal amount
- Choose the interest rate
- Enter the number of years
- Calculate simple interest
- Display the result

## Technologies Used
- HTML
- CSS
- JavaScript

## Formula
Simple Interest = (Principal × Rate × Time) / 100

## How to Use
1. Open the calculator.
2. Enter the principal amount.
3. Select the interest rate.
4. Enter the number of years.
5. Click the Calculate button.
6. View the result.
