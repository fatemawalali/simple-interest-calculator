# Code of Conduct

## Our Pledge

We want everyone who participates in this project to feel
welcome and respected. We promise to create a friendly
environment for everyone, regardless of their background,
experience, or identity.

## Our Standards

Everyone contributing to this project should:

- Be respectful and kind to others.
- Use friendly and professional language.
- Accept feedback and suggestions.
- Respect different opinions.
- Help others when possible.
- Avoid harassment, insults, and discrimination.

## Enforcement Responsibilities

The project maintainers are responsible for making sure
everyone follows this Code of Conduct.

They have the right to remove inappropriate comments,
contributions, or behavior that violates these rules.

## Scope

This Code of Conduct applies to everyone participating
in this project, including contributors and maintainers.

It applies to project discussions, issues, pull requests,
and other project-related communication.

## Enforcement

If someone experiences or notices unacceptable behavior,
they should report it privately to the project maintainer
through an appropriate contact method.

All reports will be reviewed fairly and confidentially.
The maintainer will decide what action is necessary.

## Enforcement Guidelines

The following guidelines may be used when someone
violates the Code of Conduct.

### 1. Correction
For minor inappropriate behavior, the person may
receive a warning and be asked to correct their behavior.

### 2. Warning
For more serious behavior, the person may receive
an official warning.

### 3. Temporary Ban
If the behavior continues, the person may be temporarily
banned from participating in the project.

### 4. Permanent Ban
For serious or repeated violations, the person may
be permanently banned from the project.

## Attribution

This Code of Conduct is based on the Contributor Covenant,
version 2.1.

The Contributor Covenant provides guidelines to help
create welcoming and respectful open-source communities.
